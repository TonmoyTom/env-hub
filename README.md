# ProjectDockHub

A free, open source desktop app that runs your whole local development
environment in Docker, managed from a GUI. Nobody needs to type Docker or
terminal commands.

Supported stacks (planned): Laravel first, then Node, Next.js, NestJS, and FastAPI.

## Status

Phase 0: Electron scaffold with a secure window and one allowlisted IPC call.
Docker features come in later phases. See `PLANNING.md`.

## Development

Requirements: Node.js 20 or 22, and Docker Desktop (or Docker Engine on Linux) for later phases.

```bash
npm install
npm start
```
